# todo-react

TODO-сайт на React — простий односторінковий застосунок для створення, редагування та сортування завдань.

## Огляд
Цей проєкт — невеликий Todo-list, реалізований на React + Vite з використанням Sass (SCSS). Збереження завдань відбувається в `localStorage`, частина поведінки тимчасово керується через `sessionStorage` (наприклад, показ підказок або "секретних" задач). Є підтримка пріоритетів, позначення улюблених, пошуку та редагування.

## Можливості
- Додавання, редагування та видалення завдань
- Позначення завдань як виконаних
- Відзначення улюблених (favorite)
- Зміна пріоритету (низький / середній / високий) з візуальною підсвіткою
- Пошук по тексту задачі
- Кнопка для прокрутки до першої невиконаної задачі
- "Секретні" завдання, які з'являються у певний час (наприклад, нагадування йти спати або новорічне побажання)
- Опціональне додавання задачі з IP користувача (через api.ipify.org) після підтвердження
- Збереження стану в `localStorage`, короткочасні позначки в `sessionStorage`
- Наявні aria-атрибути та прості заходи доступності

## Технології
- React 19
- Vite
- Sass (sass-embedded)
- JavaScript (ES modules)
- GH Pages (скрипт для деплою)
